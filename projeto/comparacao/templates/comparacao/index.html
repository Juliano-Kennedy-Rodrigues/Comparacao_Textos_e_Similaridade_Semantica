COMPARAÇÃO SEMÂNTICA DE ARQUIVOS

  • A primeira opção permite comparar 5 arquivos entre si, onde todos os arquivos são comparados com todos os outros (menos a si prório)
  • Para isso, clique no botão "Comparação Geral".
  • A segunda opção permite comparar até 9 arquivos com 1 arquivo específico.
  • Para isso, clique no botão "Comparação Específica".
